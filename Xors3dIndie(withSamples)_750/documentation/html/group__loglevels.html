#define LOG_NO   5

On this logging level nothing will be written in log-file.

#define LOG_FATAL   4

On this logging level only fatal errors will be written in log-file.

#define LOG_ERROR   3

On this logging level all errors will be written in log-file.

#define LOG_WARNING   2

On this logging level all errors and warnings will be written in log-file.

#define LOG_MESSAGE   1

On this logging level all message types will be written in log-file, except informative messages.

#define LOG_INFO   0

On this logging level all messages types will be written in log-file.
